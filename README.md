## 📌 Giới thiệu dự án

Dự án nghiên cứu và phát triển một Plugin mở rộng tích hợp trực tiếp vào phần mềm **QGIS** nhằm tự động hóa quy trình phân tích và trích xuất thông tin từ dữ liệu ảnh viễn thám[cite: 1].

### ✨ Tính năng chính:
- **Giao diện người dùng (GUI):** Thiết kế trực quan, dễ sử dụng bằng Python & PyQt5[cite: 1].
- **Tích hợp các mô hình Machine Learning:**
  - **SVM (Support Vector Machine):** Phân loại bề mặt ảnh viễn thám.
  - **Random Forest:** Tăng cường độ chính xác cho các vùng dữ liệu phức tạp.
  - **MLP (Multi-Layer Perceptron):** Mạng nơ-ron nhân tạo hỗ trợ bài toán phân loại đa lớp.
- **Tối ưu hóa hiệu suất:** Xử lý chính xác và ổn định với dữ liệu ảnh vệ tinh dung lượng lớn[cite: 1].
